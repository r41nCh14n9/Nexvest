## 概述與願景

### 產品定位

Nexvest 聯核投的核心使命：**「減少雜訊、提升決策品質」**

將投資資訊平台從「資訊堆疊」轉型為「決策夥伴」，同時兼顧：

- **終端投資人**: 舒適體驗、決策信心
- **廣告商**: 精準標籤、轉換價值
- **不同投資風格**: 長線價值、短線趨勢、量化交易、創新成長

### Phase 1: 核心骨架 (Q1 - 優先級最高)

#### 1.1 視覺化財報健檢系統 (Fundamental Health Monitor)

**功能描述:**

- 將 ROE、自由現金流、負債比、毛利率等核心指標轉化為視覺圖表
- 支持 5 年/10 年歷史趨勢對比
- 電燈號標示 (紅/黃/綠) 快速健康度評分

**核心指標:**

```text
健康度評分模型 (5 點制)：
┌─ 盈利能力: ROE、毛利率、淨利率
├─ 現金流: 自由現金流、營運現金流
├─ 財務穩定: 負債比、流動比率、利息覆蓋率
├─ 成長性: EPS YoY、營收 YoY
└─ 股東回報: 股息率、股票回購比
```text

**用戶族群:** 所有投資人 (覆蓋率: 100%)

**相關需求:**

- 巴菲特的護城河識別
- 達里歐的資產相關性基礎
- 終端用戶的快速查詢

#### 1.2 進階策略警示系統 (Smart Alert Engine)

**功能描述:**

- 多維度警示條件: 股價、技術面、基本面、市場情緒

##### 警示類型

| 類型             | 描述                             | 數據源   |

**推送延遲要求:** < 30 秒

- 米奈爾維尼的 VCP 識別

- 終端用戶的盤中快速反應

### Phase 2: 決策輔助工具 (Q2)

#### 2.1 個股內在價值估算器 (Intrinsic Value Calculator)

**功能描述:**

- 支持多種估值方法: DCF、本益比位階、股利折現、相對估值
- 用戶可自訂參數 (折現率、增長率、終端價值)
- 輸出 "便宜價、合理價、昂貴價" 三階段價格

**估值方法:**

| 方法                   | 目標大類           | 複雜度 |
| ---------------------- | ------------------ | ------ |
| **DCF（現金流折現）**  | 自由現金流投影     | 高     |
| **本益比位階**         | 歷史 P/E 百分位數  | 低     |
| **股利折現模型 (DDM)** | 穩定配息股票       | 中     |
| **相對估值**           | 同業 P/E、P/B 對比 | 低     |

**用戶族群:** 價值投資者、中高端用戶 (覆蓋率: 40%)

**相關需求:**

- 巴菲特的價值判斷輔助
- 終端用戶的買賣決策支持

#### 2.2 多維度選股濾網 (Advanced Stock Screener)

**功能描述:**

- 預設模組: "定存股"、"高成長"、"法人收貨"
- 自訂複雜條件: AND/OR 邏輯、多條件組合
- 即時篩選 + 結果排序

**預設濾網示例:**

```text
🔘 定存股模組
├─ 連續 5 年配息 = YES
├─ 殖利率 >= 4%
├─ EPS 成長率 (YoY) >= 5%
├─ 負債比 < 60%
└─ 排序: 由高殖利率到低

🔘 高成長模組
├─ EPS 成長率 (YoY) >= 20%
├─ ROE > 15%
├─ 本益比 < 同業平均 * 1.2x
└─ 排序: 由高成長到低

🔘 法人收貨模組
├─ 法人近 5 日淨買超 > 100 張
├─ 三大法人持股比 < 50% (成長空間)
├─ 技術面: 突破 20 日線
└─ 排序: 由高法人淨買到低
```text

**用戶族群:** 中高端用戶、專業操盤手 (覆蓋率: 30%)

**相關需求:**

- 投資人的選股輔助
- 米奈爾維尼的技術面篩選
- 伍德的破壞式創新產業篩選

#### 2.3 投資組合模擬與回測 (Portfolio Backtesting)

**功能描述:**

- 用戶輸入資產配置 (股票、ETF、現金占比)
- 模擬過去 1年/2年/5年/10年 績效
- 顯示回撤、夏普比率、最大虧損等風險指標

**回測指標:**

| 指標         | 描述               | 用途     |
| ------------ | ------------------ | -------- |
| **總報酬率** | 期末收益率         | 基准績效 |
| **年化報酬** | 年平均報酬         | 可比性   |
| **最大回撤** | 高點到低點最大跌幅 | 風險量化 |
| **夏普比率** | 風險調整後報酬     | 效率評估 |
| **勝率**     | 正報酬月份占比     | 穩定性   |

**用戶族群:** 專業操盤手、進階投資人 (覆蓋率: 20%)

**相關需求:**

- 投資人的決策信心提升
- 達里歐的全天候組合優化基礎
- 索羅斯的泡沫偵測基礎

護城河強度評分 (1-10分)：

轉換成本：判斷依據

規模優勢：判斷依據

網絡效應：判斷依據

├─ 月活躍用戶增速

#### 2.5 一條龍聯核功能 (Integrated Alert Deep Dive)

**功能描述:**

- 點擊警示後，下方自動展示:
  - 近 1 小時相關新聞摘要
  - 技術線圖 (含主要均線)
  - 交易量異常指標
  - 相關營運數據
- 一個畫面完整解答「為什麼跌/漲」

**Layout 設計:**

```text
┌─────────────────────────────────────┐
│  警示標題: TSMC 下跌 3%            │
├─────────────────────────────────────┤
│ 📰 相關新聞摘要 (過去 1 小時)       │
│ • 新聞 1: 晶圓代工產能下降         │
│ • 新聞 2: 台積電法說重點           │
│ • 新聞 3: 半導體產業新聞           │
├─────────────────────────────────────┤
│ 📊 技術線圖 (1hr K 線)             │
│    [圖表區域]                       │
├─────────────────────────────────────┤
│ 📈 成交量異常: 成交量是平均 2.1 倍  │
│ 法人淨買賣: 近 5 日淨賣 -200 張   │
├─────────────────────────────────────┤
│ 🔔 類似警示歷史: 上次下跌類似      │
│    日期: 2025-12-01  漲幅: +2.5%   │
